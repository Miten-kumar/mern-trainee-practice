# Performance Optimization Dashboard

The project demonstrates image optimization, responsive image delivery, lazy loading, Core Web Vitals monitoring, Real User Monitoring (RUM), performance budgets, resource hints, and Lighthouse-based performance auditing.

---

##  Project Overview

The goal of this task is to build a performance-focused web application and apply techniques that improve:

- Largest Contentful Paint (LCP)
- First Contentful Paint (FCP)
- Cumulative Layout Shift (CLS)
- Total Blocking Time (TBT)
- Speed Index
- JavaScript execution time
- Image loading performance
- Critical rendering path
- Network resource loading
- Accessibility
- SEO
- Real User Monitoring (RUM)
